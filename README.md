# Skribbl.io Clone - Backend API

This repository contains the Node.js and Socket.IO backend for the Skribbl.io Clone project.

## Frontend Repository

For the frontend codebase and project setup, visit:

https://github.com/Mohdsharik682/skribbl-frontend

## Live Backend

https://skribbl-backend-hcas.onrender.com

## Technologies Used

- Node.js
- Express.js
- Socket.IO

## Project Overview

The backend handles real-time communication between players, room creation, and multiplayer game functionality for the Skribbl.io Clone.
